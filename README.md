# DSH Steer and Queue Button

Use both steer and queue directly without making a choice in the settings. We deserve both!

## Packages

- [`packages/queue-steer-button`](packages/queue-steer-button/) — the plugin:
  Queue (next-step delivery after the observation) and Steer (stop the current
  step, keep the partial output, continue with the new request). Buttons are
  visible only while the agent is running; shortcuts are platform-aware
  (⌘+Return / ⌘+⇧+Return on macOS, Ctrl+Enter / Ctrl+Shift+Enter elsewhere).

See the package README for install and verification steps.
